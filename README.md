# Job search pipeline — public dashboard

A static, self-contained dashboard over an ongoing engineering job search.
**Live: https://pfeilbr.github.io/job-search-pipeline/**

Two files, no build step, no server: `index.html` reads `data.json` and renders.

## What this shows

Every application, its published base-salary band, when it went out, the work mode,
and where it stands — triaged against the pipeline's own measured response latency
rather than against a guess. Silence past the observed p90 is *going quiet*; past
roughly twice that, *presumed dead*.

## What this deliberately does not contain

This dashboard is generated by a sanitiser that works from an **allow-list**, so a
field added upstream is excluded by default rather than leaked by default. Excluded:

- contact details of any kind — name, address, phone, email, profile links
- per-application notes, which hold the answers given on every form
- cover letters
- the free-text `location` field, which was operator scratchpad and leaked a home
  town on the first pass. It is now **rebuilt from a closed vocabulary** — a
  recognised metro plus a work-mode label — rather than redacted, because redaction
  fails open on the next unanticipated phrasing.

The generator refuses to write output if a forbidden pattern appears in the rendered
bytes, so the build fails loudly instead of publishing something questionable.

Salary figures are **published bands from job postings**, not offers.
